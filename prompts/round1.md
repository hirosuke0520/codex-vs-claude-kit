このフォルダで、領収書を CSV にまとめる小さな CLI ツールを作ってください。人は途中で答えられないので、質問せず最後まで自分で判断して進めてください。

## 作るもの
- `receipt2csv.py`（Python 3）。使い方: `python3 receipt2csv.py <入力フォルダ> [-o 出力.csv]`
- 入力フォルダ直下の `.pdf` `.png` `.jpg` `.jpeg`（大文字小文字は問わない）を読み、1ファイル1行で次の列の CSV を出す
  - `file`（ファイル名）, `date`（`YYYY-MM-DD`）, `amount`（支払った合計金額・円・数字だけ）, `store`（店名）
  - 1行目はヘッダー。行はファイル名順。文字コードは UTF-8
- `-o` が無ければ標準出力に書く
- それ以外の拡張子は無視する。入力フォルダが無ければ分かりやすいエラーを出して終了コード 0 以外で終わる
- 読めないファイルや項目が取れないファイルがあっても止めない。そのファイルの行は出し、取れなかった項目は空にする
- 金額は小計・お預り・お釣り・内税ではなく「支払った合計」。和暦（令和）の日付も西暦に直す
- PDF にはテキストが入っているものとスキャン画像だけのものがある。画像は文字認識（OCR）が要る

## 条件
- ネットに出ない・外部APIを使わない（ローカル完結）。`pip install` などの追加インストールはしない
- 使ってよいもの: Python 標準ライブラリ、このマシンに入っている PyMuPDF（`import fitz`）と Pillow、`pdftotext` コマンド、macOS 標準の Vision フレームワーク（`swift` から呼んでよい）
- 作業はこのフォルダの中だけ。`samples/` は架空の領収書サンプル、`tests/test_acceptance.py` は受け入れテスト（このテストは書き換えない）
- 自分でもテストを `tests/` に足してよい

## 完了の条件
- `python3 -m unittest discover -s tests -v` が全部通る
- 最後に、作ったもの・使い方・分かっている限界を短く書いて終わる
