# 領収書CSV CLI コードレビュー

`target/SPEC.md` を基準に、`target/receipt2csv.py`、既存テスト、サンプルをレビューした。ネット接続・追加インストール・コード修正は行っていない。作業ファイルは `review/` と本書のみ。

掲載した17件はすべて、最小入力を使って実際のCLIで確認済み。未確認の推測は指摘に含めていない。重大度は、通常の支払額や領収日を黙って誤記するものを高、欠落・壊れた入力・特定レイアウトでの誤りを中、発生範囲が限られる日付の誤りを低とした。

## 実行環境・再現方法

- macOS、Python 3.14.5。既存のPyMuPDF、Pillow、pdftotext、Swift/macOS Visionを使用。
- 既存テストは **38件すべて成功**。ログは `review/existing-tests.stderr.txt`。ただし以下の追加ケースは既存テストでは検出されない。
- 最小入力は各 `review/cases/<ケース名>/receipt.pdf`。それぞれの入力フォルダにはPDFを1つだけ置いた。
- 全再現ログは `review/evidence/`。`cases.json` に期待値、各JSONに実際の行・終了コードを保存した。
- 下のコマンドはこのフォルダのルートで実行する。補助スクリプトは実CLIを呼び、標準出力・標準エラーをそのまま表示する。TMPDIRとSwiftキャッシュも `review/` 内に設定する。

```sh
python3 -B review/reproduce.py <ケース名>
# 内部で実行するコマンド:
# python3 -B target/receipt2csv.py review/cases/<ケース名>
```

全ケースの再実行:

```sh
python3 -B review/reproduce.py --all
```

既存テストの再実行（キャッシュ・一時ファイルも作業フォルダ内）:

```sh
PYTHONDONTWRITEBYTECODE=1 TMPDIR="$PWD/review/tmp" SWIFT_MODULECACHE_PATH="$PWD/review/cache" CLANG_MODULE_CACHE_PATH="$PWD/review/cache" python3 -B -m unittest discover -s target/tests -v
```

21の不具合再現入力が期待値と不一致になり、3つのPDF/OCR対照入力は期待値と一致した。全24入力でCLIの終了コードは0だった。まとめは `review/reproduction-summary.txt` と `review/evidence/verification.json`。

```csv

```

標準エラー: 空（警告なし）。


**原因の場所:** `target/receipt2csv.py:375–376` が現金の支払額をP1からcashへ分類し、`:416–419` がP2の値引前合計を先に返す。クーポンケースは`:299–302`、`:371–372` の除外判定が「適用後のお支払金額」にも当たり、P1に到達しない。支払額の見出しを、支払方法や値引語より優先する必要がある。


`malformed_number`、終了コード `0`:

```csv

receipt.pdf,,,
```

```csv
file,date,amount,store
receipt.pdf,2018-10-01,100,テスト店
```

標準エラー: 空（警告なし）。

**原因の場所:** `target/receipt2csv.py:167–171` は0を年として受け入れ、`:201–203` が2018+0へ変換する。`:215–224` は変換後の西暦の月日だけを検証し、元号の年として有効か確認しない。元号年は1以上であることを確認する必要がある。

### 17. 仕様にない1989年の下限で、有効な日付を捨てる

**何が起きるか:** 有効な1988/10/01を読み取ってもdateが空になる。終了コード0、日付の未取得警告あり。過去の領収書を対象外にする条件は仕様にない。

**最小入力:** 「テスト店」「1988/10/01」「合計 ¥100」の3行。

**再現手順:**

```sh
python3 -B review/reproduce.py old_date
```

**実際の出力:**

`old_date`、終了コード `0`:

```csv
file,date,amount,store
receipt.pdf,,100,テスト店
```

標準エラー:

```text
警告: receipt.pdf: 日付を取得できませんでした
```

**原因の場所:** `target/receipt2csv.py:222–223` が1989年より前の日付を一律に捨てる。仕様にない年の範囲で有効な日付を欠落させない必要がある。
